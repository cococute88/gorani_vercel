# 포트폴리오 성과 비교 계산 계약

## 목적

`/calculator?tab=portfolio-compare`는 미국·한국 종목으로 구성한 포트폴리오 A와 B를 동일한 기준통화에서 비교한다. 기존 `/calculator?tab=compare` 종목 비교는 변경하거나 대체하지 않는다.

## 데이터 계약

- 시세는 Yahoo Finance long-series 일봉만 사용한다.
- TR은 `adjClose`, PR은 `close`를 사용한다.
- TR의 조정종가 유효 관측치가 98% 미만이면 PR로 대체하지 않고 분석을 차단한다.
- 한국 코드는 기존 MDD 계산기의 문자열 기반 6자리, `.KS`, `.KQ` 해석을 재사용한다.
- 조회 실패 시 샘플 시세, 고정 환율, 자동 유사 티커를 사용하지 않는다.
- 같은 시장·티커는 클라이언트 요청 캐시와 서버 캐시로 재사용한다.

## Buy & Hold

MAX 원본 시계열의 공통 시작일에 각 종목을 입력 비중만큼 한 번 매수한다. 이후 보유수량은 고정하며 일간·월간·분기·반기·연간 리밸런싱을 하지 않는다. 기간 버튼과 Rolling 탭은 이미 생성된 MAX 가치 시계열을 읽을 뿐 보유 경로를 다시 만들지 않는다.

## 실제 상장 이후

포트폴리오 A·B의 모든 구성종목이 실제 데이터를 가진 날짜 중 가장 늦은 날짜를 공통 시작일로 쓴다. 종료일은 모든 실제 구성종목의 유효 데이터 종료일 중 가장 이른 날짜다. 상장 전 값과 종료 후 값은 채우지 않는다.

## Virtual Price

사용자가 Virtual을 켠 대상 종목과 직접 입력한 프록시만 사용한다. 프록시 바스켓은 지정 시작 비중으로 한 번 매수한 Buy & Hold 경로다. 모든 프록시의 실제 데이터와 사용자가 입력한 적용 시작일이 겹치는 첫 날짜부터 대상 종목의 실제 첫 데이터 직전까지만 Virtual 값을 쓴다.

실제 첫 데이터 날짜의 지수는 직전 Virtual 지수와 같게 연결하고, 그 날짜부터 대상 종목의 실제 TR 또는 PR 수익률만 누적한다. 실제 구간을 프록시로 덮어쓰지 않는다. 차트는 전체 경로 위에 Virtual 구간을 점선으로 겹쳐 표시한다.

## 기준통화

- KRW 기준: USD 종목 가격 × 일별 USD/KRW
- USD 기준: KRW 종목 가격 ÷ 일별 USD/KRW
- 같은 통화의 종목에는 환율을 적용하지 않는다.
- 휴장일은 직전 10일 안의 유효 종목 값을 유지한다. 환율은 Yahoo 장기 원본의 알려진 2008년 26일 공백을 포함하되 무제한 보간하지 않도록 직전 실제 관측치를 최대 31일까지 제한적으로 유지한다.
- 환율 조회 실패 또는 지원하지 않는 통화는 분석을 차단한다.

## 지표

기존 `computeBacktestRiskMetrics`를 사용해 일별 252 거래일 연율화, 무위험수익률 0 가정으로 MDD, Sharpe, Sortino, Calmar를 계산한다. 변동성도 동일한 일별 수익률과 252일 연율화를 사용한다. Rolling은 기존 종목 비교와 같이 월말 인덱스에서 정확히 12·36·60·120·180·240·360개월 전 같은 달의 월말을 비교한다.

## 해석상 한계

Yahoo 조정종가는 공급자 정정과 시장별 기업행사 처리 품질에 영향을 받는다. Virtual은 실제 거래 이력이 아니며, 프록시 선택·비중·통화 노출에 따라 결과가 크게 달라진다. 거래비용, 세금, 슬리피지는 포함하지 않는다.
