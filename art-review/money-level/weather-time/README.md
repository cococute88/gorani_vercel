# Money Level Time × Weather Art Review

Development-only Phase A artifacts. These files are not connected to the Money Level runtime.

## Open the gallery

From the repository root:

```powershell
python -m http.server 4173
```

Then open:

```text
http://localhost:4173/art-review/money-level/weather-time/
```

The gallery presents the 4×4 asset matrix and supports Variant, Original, 50/50 Overlay, Flicker, and Landmark Grid modes. Click any card to compare it with the relevant time and weather references.
